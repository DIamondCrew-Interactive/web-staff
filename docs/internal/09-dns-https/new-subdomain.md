# Vytvoření subdomény

## K čemu slouží

Vyber schválené jméno.

## Kde a jak běží

Veřejné A záznamy směřují na 51.254.46.124; TLS a HTTP routing řeší NPM.

## Postup

1. Vyber schválené jméno
2. Vytvoř A/CNAME
3. Připrav fungující backend
4. NPM Proxy Host
5. HTTPS
6. Verification

## Ověření výsledku

DNS, HTTP routing a certifikát odpovídají témuž jménu.
