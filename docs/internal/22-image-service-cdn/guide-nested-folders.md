# Jak vytvořit nested folders

## Předpoklady
Povolený Discord účet pro /manage. Obrázky jsou veřejné; žádné citlivé soubory. Aktuální složku ověř v breadcrumbs.
## Postup
V kořeni otevři Nová složka a zadej inventory/food. Otevři inventory a poté food; breadcrumbs umožní návrat. Path je relativní k právě otevřené složce, proto nezadávej znovu inventory/food při otevřeném inventory.
## Ověření a řešení potíží
Zkontroluj výslednou cestu, metadata a případnou veřejnou URL. Chybu neopravuj blind overwrite nebo hromadným mazáním. [Podrobný postup](folder-structure.md), [Troubleshooting](troubleshooting.md).
