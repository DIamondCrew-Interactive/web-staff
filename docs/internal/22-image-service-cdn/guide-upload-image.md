# Jak uploadnout obrázek

## Předpoklady
Povolený Discord účet pro /manage. Obrázky jsou veřejné; žádné citlivé soubory. Aktuální složku ověř v breadcrumbs.
## Postup
Otevři kostka. Vybrat obrázky → vyber 1.png → zkontroluj review → Nahrát obrázky. Bez výslovného overwrite se existující 1.png nepřepíše. V detailu ověř image/png a náhled.
## Ověření a řešení potíží
Zkontroluj výslednou cestu, metadata a případnou veřejnou URL. Chybu neopravuj blind overwrite nebo hromadným mazáním. [Podrobný postup](upload.md), [Troubleshooting](troubleshooting.md).
