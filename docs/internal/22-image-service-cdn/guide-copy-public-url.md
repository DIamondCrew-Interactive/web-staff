# Jak získat veřejný odkaz

## Předpoklady
Povolený Discord účet pro /manage. Obrázky jsou veřejné; žádné citlivé soubory. Aktuální složku ověř v breadcrumbs.
## Postup
Vyber kostka/1.png. V detailu je PUBLIC URL https://img.dcrp.cz/kostka/1.png. COPY URL uloží odkaz do clipboardu; pokud browser oprávnění odmítne, označ URL pole a zkopíruj ručně. Otevři v anonymním okně a ověř obrázek.
## Ověření a řešení potíží
Zkontroluj výslednou cestu, metadata a případnou veřejnou URL. Chybu neopravuj blind overwrite nebo hromadným mazáním. [Podrobný postup](public-url-structure.md), [Troubleshooting](troubleshooting.md).
