# NPM 502

## K čemu slouží

502 znamená selhání upstreamu, ne automaticky DNS klienta.

## Kde a jak běží

nginx-proxy-manager_app_1 na DIA-01, porty 80/443 a admin 81; připojení do diamondcrew-proxy.

## Postup

1. 502 znamená selhání upstreamu, ne automaticky DNS klienta
2. Ověř hostname/port/scheme a sdílenou síť
3. Host localhost z NPM neukazuje na DIA-01

## Ověření výsledku

Přímý upstream ze sítě NPM funguje a potom i veřejný host.
