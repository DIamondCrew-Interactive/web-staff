# Používání Server Manageru

## K čemu slouží
Panel klient spravuje vlastní server; vytvoření serveru, nodu a Eggu je práce administrátora.

## Jak začít
Začni klientským návodem konkrétního úkolu. Kroky Admin vyžadují správce; běžný uživatel nepřebírá administrátorský účet.

Chybějící položka v panelu obvykle znamená chybějící oprávnění nebo limit serveru. Před změnou běžícího serveru ulož konfiguraci a zálohu dat. Společný [postup před změnou a při selhání](../01-getting-started/index.md) najdeš v úvodu příručky.
