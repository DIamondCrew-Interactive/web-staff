# Bezpečná reinstalace

## K čemu slouží

Nejdřív vytvoř a ověř zálohu.

## Kde a co nastavit

1. Nejdřív vytvoř a ověř zálohu
2. Zjisti, co konkrétní Egg reinstall přepisuje
3. Server
4. Settings
5. Reinstall potvrď pouze pro správnou instanci
6. Sleduj instalační log

## Ověření výsledku

Instalace skončí úspěšně a start/stop/restart zachová potřebná data. Reinstall není backup.
