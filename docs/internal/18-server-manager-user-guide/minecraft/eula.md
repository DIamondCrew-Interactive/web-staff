# Minecraft EULA

## K čemu slouží

Před spuštěním přečti aktuální Minecraft EULA.

## Kde a co nastavit

1. Před spuštěním přečti aktuální Minecraft EULA
2. Souhlas je rozhodnutí oprávněného provozovatele
3. Teprve potom změň příslušnou EULA volbu/soubor

## Ověření výsledku

Server již nekončí na chybě vyžadující přijetí EULA; neautomatizuj souhlas bez autorizace.
