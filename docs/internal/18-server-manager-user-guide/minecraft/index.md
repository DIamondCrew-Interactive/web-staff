# Výběr Minecraft serveru

## K čemu slouží

Rozliš Vanilla, Paper, Forge a proxy.

## Pro koho

Uživatel Server Manageru; krok označený Admin vyžaduje správce. Není potřeba znát Linux pro běžnou klientskou část.

## Kde a jak běží

Panel klient spravuje vlastní server; vytvoření serveru, nodu a Eggu je práce administrátora.

## Než začneš

Vyber správný server a ověř svá oprávnění. U běžícího PROD domluv údržbu a připrav zálohu před změnou.

## Kde a co nastavit

1. Rozliš Vanilla, Paper, Forge a proxy
2. Paper používá plugins, Forge mods
3. Použij správný existující Egg nebo požádej správce o nový

## Ověření výsledku

Vybraný runtime podporuje požadovanou verzi hry i rozšíření.

## Aktualizace a rollback

Před změnou ulož původní nastavení a vytvoř backup souvisejících dat. Pokud ověření selže, zastav nové zápisy a vrať poslední kompatibilní nastavení nebo ověřenou zálohu; obnovu přes živá data potvrzuje vlastník serveru.

## Řešení problémů

Chybějící položka UI obvykle znamená nedostatečné oprávnění nebo limit serveru. Předej správci název serveru, čas a redigovanou chybu. Neopakuj destruktivní operaci naslepo.
