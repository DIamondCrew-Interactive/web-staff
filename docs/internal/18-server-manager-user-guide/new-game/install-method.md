## K čemu slouží

Rozliš SteamCMD, oficiální archive, Git release a licencovaný installer.

## Kde a co nastavit

1. Rozliš SteamCMD, oficiální archive, Git release a licencovaný installer
2. Ověř checksum a pravidla redistribuce
