# Zjištění potřebného runtime

## K čemu slouží

Ověř engine, Java/.NET/GLIBC či jinou závislost.

## Kde a co nastavit

1. Ověř engine, Java/.NET/GLIBC či jinou závislost
2. Ověř cílovou architekturu
3. Vyber dostupný důvěryhodný image, ne vymyšlený tag

## Ověření výsledku

Čistý runtime spustí executable bez chybějících knihoven.
