# Parser konfiguračních souborů

## K čemu slouží

Zvol správný parser formátu souboru.

## Kde a co nastavit

1. Zvol správný parser formátu souboru
2. Nahrazuj konkrétní známé keys
3. Zálohuj původní config a testuj, že se zachová zbytek nastavení

## Ověření výsledku

Po restartu aplikace načte syntakticky validní config bez přepsání uživatelských dat.
