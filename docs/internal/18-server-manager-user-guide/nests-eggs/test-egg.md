# Testování Eggu

## K čemu slouží

Vytvoř izolovaný DEV server.

## Kde a co nastavit

1. Vytvoř izolovaný DEV server
2. Otestuj install/start/stop/restart/reinstall, allocations, variables a backup/restore
3. Zaznamenej engine a image verzi

## Ověření výsledku

Každý test má skutečný výsledek, ne předpokládané OK.
